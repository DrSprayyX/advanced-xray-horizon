# Advanced XRay (Fabric) on Horizon

A Horizon native-mod bundle generated by horizon-port from `advanced-xray-fabric-26.3.0.4.jar`. It builds as it is and plays like vanilla: every injection that is on leaves the game unchanged until its `TODO` is filled in. 6 injections are on; 3 are written commented out in `mixins/xray/horizon-mixin.toml`, with why.

## Build it

Create the `.hnmod` package on Windows with PowerShell:

```powershell
.\build.ps1
```

The package is written to `target/xray-0.1.0.hnmod`. It contains the native-mod manifest and the mixin sources.
To build the mod from this source folder for a game instance (a separate step; the launcher downloads its own Rust the first time):

```bash
horizon-launcher native-build "<this folder>" --trust-native-code
```

Native mods run with your rights and aren't sandboxed: build only code you have read. `cargo test` here runs `runtime.rs`'s own tests without the game.

## Limits

- The mod's own logic that doesn't need the game is translated into `runtime.rs` (`pub mod java`): Translated 8 of 186 methods (1 more is done another way in Horizon) and 18 of 30 static fields to Rust; 1 of 3 Fabric event handlers. Code that uses Minecraft classes isn't: each helper lists the game calls its Java makes and what they are in Horizon. See `report/translation.md`.
- `BEFORE_CALL`, `AFTER_CALL`, `MODIFY_ARG` and `WRAP_OPERATION` select the called function by name (`selector`), with `require` counted in the target's source. horizon-mixins checks both when it plans: a mismatch fails the build with a message, it never applies silently.
- Raw targets are functions of one Horizon commit: a newer Nightly may move them.
